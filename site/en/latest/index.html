High-fidelity co-simulation for water cyber-physical system security

CPS² Lab · Water CPS Security

Hydro-CPS-Sim

A co-simulation platform for the security research of water distribution cyber-physical systems. It connects hydraulic dynamics, PLC control, SCADA communications, and network simulation to support attack-impact evaluation and cross-layer analysis.

Get started →Explore architectureGitHub ↗

Project Overview

What can the platform do?

▤Cross-layer co-simulation

Link hydraulic models, control logic, and communication processes to study how cyber events affect the physical network.

⌁Attack-impact evaluation

Support research into MITM, DoS, and PLC logic modification scenarios. Runnable cases depend on the published code and configurations.

▦Reproducible workflows

Organize experiments through configuration files and scripts, and export logs and CSV results for analysis.

◇Research extensibility

Investigate control, network, and hydraulic effects within a modular experiment framework.
