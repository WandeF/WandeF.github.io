CPS² Lab · Water CPS Security

Hydro-CPS-Sim

面向供水网络的信息物理系统安全联合仿真平台。将水力过程、PLC 控制、SCADA 通信与网络仿真连接起来，为网络攻击评估、跨层影响分析和防御研究提供可扩展的实验环境。

Project Overview

研究平台能做什么？

▤跨层联合仿真

连接水力模型、控制逻辑和通信过程，观察网络层事件如何影响物理水网。

⌁攻击影响评估

为 MITM、DoS 与 PLC 逻辑篡改等研究场景提供实验与分析框架；实际可执行场景以源码和配置为准。

▦可复现实验流程

以配置文件组织仿真，通过脚本启动多组件闭环，并导出运行日志与 CSV 结果。

◇面向研究扩展

围绕控制、网络和物理层扩展实验设置，用于研究攻击传播、异常检测及防御策略。

平台关注一个核心问题：网络攻击如何通过数据采集、控制决策和执行过程，逐步传播到物理水力系统？

从哪里开始？

  1. 阅读项目简介，了解研究问题与适用范围。
  2. 查看安装与环境，确认操作系统与依赖。
  3. 跟随快速开始，运行示例水网。
  4. 参考攻防实验，设计基线与攻击对照。
