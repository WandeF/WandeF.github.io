# 项目简介

Hydro-CPS-Sim 是一个围绕**供水系统（Water Distribution Systems）**构建的 CPS 安全联合仿真研究平台，主要服务于工业网络攻击影响分析、攻击路径研究和防御方法验证。

## 研究动机

传统水力模拟工具擅长计算流量、压力、水箱水位等物理变量，但难以独立体现真实控制和通信过程；网络仿真工具能够刻画时延、丢包和拓扑，却往往缺少真实水力反馈。将两者在闭环中整合，可以分析攻击是否、何时以及如何影响物理系统。

## 项目组件

| 组件 | 在研究平台中的作用 |
| --- | --- |
| DHALSIM-epynet / EPANET | 水网水力计算及物理状态更新 |
| OpenPLC | PLC 程序执行与控制逻辑 |
| ns-3 | 通信网络建模与仿真 |
| Linux Network Namespace | 将主机网络过程映射到隔离网络环境 |
| Python 协调与分析模块 | 配置读取、组件编排、状态交互和实验结果导出 |

## 典型研究问题

- 攻击导致的数据篡改，在哪个控制轮次改变 PLC 决策？
- 丢包或通信超时是否必然引起泵阀控制偏离？
- 相同的物理异常，是否可能来自不同的网络和逻辑原因？
- 如何将网络日志、控制轨迹和水力变量关联起来进行因果分析？

## 当前边界

该项目旨在科研仿真和方法验证，不是现实供水设施的运维控制软件。不同攻击场景的可用性、参数名称和示例数据需与对应提交版本核对。任何未经过验证的实验结果不应作为真实供水系统风险的直接量化结论。
